# 🔤 Flan-T5 Few-Shot Translation (English to Spanish)
This project leverages **Google's Flan-T5 model** to **translate English articles into Spanish** using **Few-Shot Learning**.  

---

## 🚀 Project Features
✅ **Uses Flan-T5 for text translation**  
✅ **Implements Few-Shot Learning for better translation quality**  
✅ **Utilizes CNN/DailyMail dataset for training and testing**  
✅ **Allows prompt optimization for better results**
